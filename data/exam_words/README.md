# 考点词表示例数据

`zhongkao_sample.csv` 是**结构示例**，用来说明导入格式与查表行为，**不是官方中考考纲词表**。

- 正式词表请按同样的列结构整理后，用 `flask --app wsgi import-exam-words <csv>` 导入。
- `years` / `papers` 留空时，标签只显示到「中考考纲·高频」，不会显示年份卷别（宁缺勿假）。
- 词表补齐后重新导入即生效，历史文章的标签会在下次读取时自动变完整（实时查表，不回写句子表）。

## 列说明

| 列 | 说明 |
|---|---|
| `lemma` | 词的原形，统一小写 |
| `pos` | 词性，如 `v.` / `n.` / `adj.`；同一词多个词性可写多行 |
| `level` | `zhongkao` 或 `gaokao` |
| `band` | `high` / `mid` / `low`，决定讲解优先级 |
| `years` | 出现年份，分号分隔，如 `2024;2025`；可空 |
| `papers` | 卷别，分号分隔，如 `全国乙卷`；可空 |
| `senses` | 高频义项，分号分隔，供提示词参考 |
| `source` | 数据来源标识，便于追溯 |
