# 英语精读教练

上传一篇英语文章，先看全文骨架，再逐句学词汇和语法，生词自动进入复习队列。
定位是**备考**：重点对标近三年中高考高频词，并把同一个词在不同句子里的不同意思摆在一起对比。

完整设计见 [docs/PROJECT-PLAN.md](docs/PROJECT-PLAN.md)。

## 现在能做什么（M1）

浏览器打开 **http://127.0.0.1:5000/** → **上传文章图片** → 开始分析，可以看到：

- 全文结构：体裁、主旨、段落作用、论证链、阅读建议
- 逐句精讲：译文、句法骨架、重点词（标注考纲/真题标签）、语法点与考法
- 识别出的原文（可展开核对），以及每次调用的 token 与成本

图片由**视觉大模型**直接转写，不使用本地 OCR 库；切句、断段、标点同样全部由模型完成。
支持拖拽、点击选择、Ctrl+V 粘贴截图，一次最多 5 张（多页文章按顺序拼接）。

尚未实现：多语境对比、生词复习、测验、任务化与真实部署（M2–M4）。

## 启动（推荐：双击）

在项目根目录**双击 `start.cmd`**。它会自动完成首次安装、建库、启动服务，并在浏览器打开
**http://127.0.0.1:5000/**。

> 窗口要一直开着，关掉就等于停止服务。想停服务按 `Ctrl+C`。
> 端口被占用时会提示，换一个端口即可。

手动启动（等价）：

```powershell
cd backend
..\.venv\Scripts\flask.exe --app wsgi serve --port 5000
```

### 打不开时按顺序排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 浏览器"无法访问此网站" | 服务没在运行 | 双击 `start.cmd`，确认窗口里出现 `http://127.0.0.1:5000/` |
| 页面是黑的/没有样式，或提示"需要通过本地服务打开" | 直接双击了 `web/index.html` | 不要双击 HTML，用 `start.cmd` |
| 提示"禁止运行脚本" | PowerShell 执行策略限制 | 用 `start.cmd`，它不经过 PowerShell |
| 提示端口 5000 已被占用 | 旧进程还在 | 关掉旧窗口，或 `flask --app wsgi serve --port 5001` |
| 页面顶部显示 FIXTURE MODE | 没配 Key | 复制 `backend/.env.example` 为 `backend/.env` 并填 `LLM_API_KEY` |

默认模型配置为阿里云百炼 `qwen3.8-max`。在百炼华北2（北京）地域创建 API Key 后，填入 `backend/.env` 的 `LLM_API_KEY`；不能继续使用其他服务商的 Key。没有配置 Key 时，程序用录制的测试夹具跑通链路（界面能用，但图片不会被真正识别）。

细节见 [backend/README.md](backend/README.md)。

## 目录

```
backend/   Flask API + 静态前端托管
web/       纯静态前端（原生 HTML/CSS/JS，零构建，赛博科技风）
data/      示例词表、示例文章与示例图片、SQLite 数据库
scripts/   dev.ps1（PowerShell 启动）、smoke.*（命令行冒烟）
docs/      项目计划
start.cmd  一键启动（双击）
```

## 关键约束

所有文本处理（切句、断段、标点、统计）都由大模型完成，本地不做任何规则处理；
**图片也不用本地 OCR**：图片直接交给视觉模型转写，本地只做 base64 编码（传输格式）。
本地只负责 JSON 结构校验、偏移数值平移、查表回填考点标签。
